# Contributing

Only submit standalone, generalized changes to CQF interfaces, JSON Schemas, conformance rules or public documentation.

- Explain changes without identifying any non-public project.
- Never include imported project material, external repository URLs, feedback, images, media, generated outputs, secrets or real-case fixtures.
- Provide compatibility notes whenever a schema or lifecycle state changes.
- Describe expected PASS, FAIL and UNKNOWN handling explicitly.
- Review filenames, links, commit messages and diffs for inadvertent disclosure.

Licensing and stable governance are to be decided. No external integration is required to use the draft specification.
