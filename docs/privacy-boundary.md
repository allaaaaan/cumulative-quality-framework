# Public-only abstract specification

This repository is a public specification and must remain free from information about any private, proprietary or customer project.

## Allowed
- Generalized interfaces, state models, JSON Schemas and normative behavior.
- Independently published references to publicly available technology.
- Fully synthetic standalone conformance specifications.

## Never include
- Private project names, repository links, identifiers, logs or issue references.
- Source code, media, prompts, generated outputs, feedback or findings from external projects.
- Real-world regression samples, copied fixtures or case-specific evaluation results.
- Indirect identifying metadata in Git history, commit messages, examples or documentation.
- Automated imports, synchronization or mirrors from private sources.

Contribution review must inspect all files, embedded links and the complete diff. An abstract proposal that cannot be explained independently without external proprietary context must not be published here.

CQF specifies external integration contracts; it never ingests implementation data itself.
